BARAMEEL — V FRIES FAMILY ASSETS

This is the dedicated artwork folder for the V FRIES family.
Keep all V Fries family-screen and product artwork inside this folder.
Do not place general Menu Families Home artwork here.

Folder map:
family-screen/v-fries-family.webp — Main V Fries family selection screen.
products/nano-volt/product-screen.webp — Nano Volt product detail screen.
products/nano-volt/anatomy.webp — Nano Volt component/anatomy screen.

Future V Fries products should each receive their own folder under products/.
All artwork must be WebP. Keep exact lowercase filenames and paths.
The page code reads these exact paths; do not rename them without updating code.
